# Reproducibility check

The analysis and figure scripts were run from a clean checkout (paths set via
`config.py`). Intermediate derivatives were regenerated by the pipeline; every
manuscript number was then reproduced from those outputs by `11_paper_numbers.py`.

## Manuscript numbers reproduced

| Quantity | Value | Source script |
|---|---|---|
| Any-disorder prevalence, three primary decisions (full criteria) | 1.9-49.9% | 06_multiverse_spec -> make_fig12 |
| Any-disorder prevalence, full grid (incl. threshold/subthreshold) | 1.9-56.8% | 06_multiverse_spec |
| Ever-met vs current (any disorder) | +22.0 pp on 25.2% base (-> 47.2%) | 08_single_lever |
| Phobia decomposition (phobia alone; anxiety with / without phobia) | 8.8%; 10.6% / 2.8% | aux_anxiety_decomposition |
| Non-administration (555) miscoding rate | 30.9% | aux_missingness_audit |
| Informant agreement, baseline | mean kappa = 0.04 (range 0.00-0.27) | 10_informant_discrepancy |

## Scope of verification

Scripts that read only pipeline-internal derivatives (06-11, the `aux_` scripts, and
all figures) were executed end-to-end and reproduced the values above. The
dataset-build scripts that ingest the access-controlled raw ABCD tables (01-04, 12,
15) are parameterized and compile, and produce the seeded derivatives by construction,
but were not re-executed in this audit because the raw inputs are not redistributable.
